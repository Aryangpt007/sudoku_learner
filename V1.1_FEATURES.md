## 🔄 Undo/Redo System

### Overview
Full undo/redo functionality for all user actions!

### Features
- **Track up to 100 moves** (configurable in settings)
- **Undo anything**: Cell values and pencil marks
- **Visual feedback**: Buttons show count of available undos/redos
- **Keyboard shortcuts**: Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y
- **Smart history**: Clears redo stack when new move is made

### How to Use

#### Keyboard
```
Ctrl+Z        - Undo last move
Ctrl+Shift+Z  - Redo
Ctrl+Y        - Redo (alternative)
```

#### Mouse
```
Click ↶ Undo (5)  - Undo (shows count)
Click ↷ Redo (3)  - Redo (shows count)
```

### What Can Be Undone?
- ✅ Entering a number
- ✅ Clearing a cell
- ✅ Adding pencil marks
- ✅ Removing pencil marks
- ❌ Generating new puzzle (creates new history)
- ❌ Importing puzzle (creates new history)
- ❌ Auto-fill pencil marks (not tracked)

### Technical Details
- Uses `HistoryManager` class
- Each move stored as `Move` object
- Separate stacks for undo and redo
- Memory-efficient (only 100 moves max)
- No performance impact

## ⚙️ Settings & Preferences

### Overview
Customize the application to your preferences!

### How to Open
- **Keyboard**: `Ctrl+,`
- **Menu**: File → Settings...

### Settings Tabs

#### 1. General Tab
**Default Difficulty**
- Choose: Very Easy, Easy, Medium, Hard, Expert
- Used for new puzzles

**Max Undo History**
- Range: 10-500 moves
- Default: 100
- Higher = more memory usage

**Confirmations**
- ☑ Confirm before solving instantly
- ☑ Confirm before clearing puzzle
- Toggle as needed

#### 2. Appearance Tab
**Theme**
- Light (current)
- Dark (coming soon)

**Pencil Mark Font Size**
- Range: 8-14 pt
- Default: 10
- Larger = easier to read
- Smaller = fits more in cell

**Cell Size**
- Range: 50-80 pixels
- Default: 60
- Affects overall grid size

**Animation Speed**
- Slow (2 seconds per step)
- Normal (1 second per step)
- Fast (0.5 seconds per step)
- Instant (no delay)
- Used for "Play All Steps"

#### 3. Gameplay Tab
**Show Errors**
- Red background for invalid moves
- Default: ON

**Auto-update Pencil Marks**
- Update marks after each move
- Default: OFF
- Can slow down gameplay

**Highlight Same Numbers**
- Yellow highlight for matching values
- Default: ON

**Show Timer**
- Display elapsed time
- Default: OFF
- Tracks solve time

**Sound Effects**
- Enable sounds (future feature)
- Default: OFF

#### 4. Colors Tab
Customize these colors:
- Background
- Initial Cell
- Selected Cell
- Highlight
- Same Number
- Error

Click color box to open color picker.

### Applying Settings
1. Make your changes
2. Click **Apply**
3. Most changes take effect immediately
4. Some require restart

### Resetting to Defaults
- Click **Reset to Defaults**
- Confirms before resetting
- Resets all tabs to original values

### Settings File
- Saved to: `~/.sudoku_learner_settings.json`
- Persists between sessions
- Can be manually edited
- Automatically created on first save

## 🔍 Troubleshooting

### Undo/Redo Not Working
- **Check**: Are you editing initial (given) cells?
  - Solution: Can only undo user moves
- **Check**: Is history full?
  - Solution: Increase max history in settings

### Keyboard Shortcuts Not Working
- **Check**: Is focus on the grid?
  - Solution: Click on grid first
- **Check**: Using correct modifier key?
  - Solution: Use Ctrl, not Alt or Cmd

### Settings Not Saving
- **Check**: Do you have write permissions?
  - Solution: Check home directory permissions
- **Check**: Did you click Apply?
  - Solution: Must click Apply, not just OK

### Pencil Marks Too Small
- **Solution**: Settings → Appearance → Increase font size to 12-14

### Animation Too Slow/Fast
- **Solution**: Settings → Appearance → Change animation speed
