## ⌨️ Essential Keyboard Shortcuts

### Most Used
| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Space` | Toggle Pencil Mode |
| `Ctrl+H` | Get Hint |
| `Ctrl+K` | Check Solution |
| `F1` | Learning Module |
| `Ctrl+,` | Settings |

### File Operations
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New Puzzle |
| `Ctrl+O` | Open/Import |
| `Ctrl+E` | Export |

### Solver Operations
| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Solve Step-by-Step |
| `Ctrl+Right` | Next Step |
| `Ctrl+R` | Play All Steps |
| `Ctrl+I` | Solve Instantly |

## ✨ New Features Quick Tour

### 1. Undo/Redo
- Made a mistake? Press `Ctrl+Z`
- Changed your mind? Press `Ctrl+Shift+Z`
- Button shows count: ↶ Undo (5)

### 2. Pencil Mode Indicator
- Look for the ✎ icon
- Gray = OFF, Orange = ON
- Quick toggle with `Space`

### 3. Settings
- Press `Ctrl+,` to open
- Change pencil size, colors, confirmations
- Everything saves automatically

### 4. Play All Steps
- Press `Ctrl+S` to analyze
- Press `Ctrl+R` to auto-play
- Watch all solving techniques!

## 🎯 Quick Workflow

1. **Start**: `python main_v11.py`
2. **New Puzzle**: `Ctrl+N`
3. **Play**: Use arrow keys + numbers
4. **Stuck?**: `Ctrl+H` for hint
5. **Mistake?**: `Ctrl+Z` to undo
6. **Learn**: `F1` for lessons
7. **Check**: `Ctrl+K` when done

## 💡 Pro Tips

1. **Use keyboard shortcuts** - Much faster!
2. **Enable pencil marks** - Press `Space`, type 1-9
3. **Auto-fill marks** - `Ctrl+P` to start
4. **Learn techniques** - `Ctrl+S` then `Ctrl+R`
5. **Customize** - `Ctrl+,` for your preferences

## 🐛 Troubleshooting

**Shortcuts not working?**
- Click on the grid first to focus

**Can't undo?**
- Only user moves can be undone
- Initial cells are protected

**Settings not saving?**
- Click "Apply" button
- Check home directory permissions
